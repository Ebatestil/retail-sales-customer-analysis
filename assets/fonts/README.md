# Poppins

Poppins Regular (400), SemiBold (600) and Bold (700) are bundled from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/poppins).
They are distributed under the SIL Open Font License in `OFL.txt`.

The report builder embeds these fonts in the HTML report and standalone SVG
charts so they work offline without installing a system font.
